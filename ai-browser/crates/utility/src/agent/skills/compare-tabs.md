1. `list_tabs`, then `read_page` for each tab the user means (ask which if it is unclear).
2. Build a table: one row per criterion that matters to the user (price, features, dates, claims), one column per tab.
3. End with a recommendation and the single biggest trade-off. Mark anything a page did not state as "not stated".
